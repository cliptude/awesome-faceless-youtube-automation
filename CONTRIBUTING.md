# Contribution guidelines

Thanks for helping. A good entry saves a faceless creator time or keeps their channel safe.

- Add one item per pull request, at the end of the section it belongs in.
- Use this format: `- [Name](https://link) - Short description that ends with a period.`
- Link to the tool's own site or repository, not to an affiliate or tracking link.
- Say what the tool does for a faceless channel, not how great it is.
- Free footage sources must say how they're licensed.
- No tools for buying views, subscribers or engagement, re-uploading other people's videos, or getting around YouTube's policies.
- If you work on the tool you're adding, say so in the pull request.
